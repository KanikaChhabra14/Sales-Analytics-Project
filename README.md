# Sales Analytics Dashboard

## Project Overview

This project analyzes sales data using SQL and Microsoft Power BI to understand sales performance and identify important business trends.

## Tools Used

- MySQL
- Microsoft Power BI
- SQL

## Project Analysis

The project includes analysis of:

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Sales per Order
- Monthly Sales Trend
- Sales by Category
- Sales by City
- Top 5 Products by Sales
- Top 5 Customers by Sales

## Dashboard Features

The Power BI dashboard contains interactive visuals and slicers for Category, City, and Order Date, allowing users to explore the sales data dynamically.

## SQL Analysis

SQL queries were used to perform sales analysis using Customer, Product, and Orders data.

## Outcome

The dashboard provides a clear view of sales performance and helps identify high-performing categories, cities, products, and customers.
